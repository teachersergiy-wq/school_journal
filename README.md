# Шкільний журнал

Мобільний PWA-каркас класного журналу. T-030 використовує лише вигадані демонстраційні дані; підключення Supabase заплановане окремо в T-031/T-032.

## Вимоги
- Node.js 20 або новіший
- npm

## Локальний запуск
```sh
cp .env.example .env
npm run dev
```
Відкрийте http://localhost:4173. Для демонстраційного входу введіть будь-яку коректну email-адресу та непорожній пароль. Це не справжня автентифікація: дані не надсилаються на сервер.

## Перевірка та збірка
```sh
npm run check
npm run build
npm run preview
```
Статичний результат збірки буде в `dist/`. Для перевірки PWA/service worker відкривайте застосунок через HTTP, а не через `file://`.

## Налаштування
Скопіюйте `.env.example` у `.env`. Підтримуються `SJ_DATA_SOURCE`, `SJ_SUPABASE_URL`, `SJ_SUPABASE_ANON_KEY`. У T-030 використовуйте `SJ_DATA_SOURCE=mock`. Supabase-реалізація є заглушкою до T-031; збірка з `SJ_DATA_SOURCE=supabase` навмисно завершується помилкою.

Не додавайте `.env`, паролі, service-role keys або реальні дані учнів до Git. Усі учні в демонстрації вигадані.

## Реалізовано в T-030
- екран входу без реєстрації та відновлення пароля;
- список журналів за предметом і класом;
- список дат уроків;
- read-only вікно уроку з характеристиками з DATA_CONTRACT;
- in-memory mock repository та Supabase integration stub;
- manifest і service worker для app shell; офлайн-записів немає.

Вхід демонстраційний, зміни не зберігаються. Не використовувати з реальними даними учнів. Див. [docs/STACK.md](docs/STACK.md).
